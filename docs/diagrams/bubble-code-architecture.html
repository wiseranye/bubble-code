Architecture · bubble-code

bubble-code 整体架构

终端里的编码智能体。界面只负责输入与渲染，会话状态持有对话记录，运行循环在钩子处维护上下文，并调用模型与工具。

Composition

启动装配

src/cli.ts 是唯一的装配点：读取 settings、构建 ModelCatalog 与 ToolRegistry，再交给会话工厂。每个会话建一个 Agent，Skill 目录在此时扫描一次，之后只消费这份快照。

Run loop

一次 run 的内循环

每个 turn 前先跑 prepareTurn 钩子（刷新系统提示词、超阈值则压缩），再向模型发起流式请求。工具按顺序执行，结果回灌历史，直到模型不再发起工具调用。

Representations

三套表示

协议消息发给模型，聊天消息给界面渲染，会话文件条目用于重放。压缩写入 compaction 条目，恢复时据此重建上下文。
